# Global E-Commerce Sales Analysis Dashboard

## Project Overview
This project analyzes global e-commerce sales data using SQL Server and Power BI. The project focuses on data cleaning, business analysis, SQL querying, and interactive dashboard creation.

- SQL Server
- Power BI
- GitHub

- Joins
- Date Functions
- CTEs
- Subqueries
- Window Functions
- CASE WHEN

---

## Dashboard Features
- KPI Cards
- Monthly Sales Trends
- Top Selling Products
- Sales by Country
- Regional Sales Analysis
- Profit by Category
- Interactive Filters
