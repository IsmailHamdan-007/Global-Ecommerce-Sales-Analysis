# 🌍 Global Ecommerce Sales Analysis

## 📌 Project Overview

This project focuses on analyzing global ecommerce sales data using **SQL Server** and **Power BI** to generate business insights related to sales performance, customer behavior, product analytics, and profitability.

The project includes:
- Data cleaning using SQL
- Business analysis using SQL queries
- Advanced SQL concepts
- Interactive Power BI dashboards
- Business performance insights

---

# 🛠️ Tools & Technologies Used

- SQL Server
- Power BI
- GitHub
- CSV Dataset
